# 能力评价三阶段与分布模型选择逻辑

> 用途：引擎计算分叉的决策依据；也是模式A/B 解释"为什么这么算"的知识源。

## 三阶段能力评价（新版第 6/7/8 章）

| 阶段 | 指数 | 用途 | 数据条件 | 变差来源 |
|---|---|---|---|---|
| 机器性能 | Pm / Pmk | **设备放行**（新设备验收、大修后） | 短期连续取样（典型 ≥50 件，同批料同操作员） | 仅设备变差 |
| 过程性能 | Pp / Ppk | **过程放行**（试生产/PPAP 阶段） | 覆盖较长时段，含更多变差源 | 总变差（总体 s） |
| 过程能力 | Cp / Cpk | **量产持续监控** | 过程受控（控制图证明）后 | 组内变差（σw=Rbar/d2） |

三者抽样方案、计算前提不同，**不可混用**。审核常见问题：拿短期数据报 Cpk、过程未受控就报 Cpk。

## 计算分叉决策树（引擎硬编码）

```
输入数据 + 规格
  │
  ├─ 1. 稳定性判定（控制图 + 所选判异准则）
  │     ├─ 受控 → 允许 Cp/Cpk（组内σ）+ Pp/Ppk（总体s）
  │     └─ 不受控 → 仅 Pp/Ppk，报告声明不受控，指向 OCAP
  │
  ├─ 2. 分布判定（Anderson-Darling，α=0.05）
  │     ├─ 正态 → 经典公式（分位数法退化为同一结果）
  │     └─ 非正态 →
  │           ├─ N ≥ 2000 → 允许经验分位数法
  │           └─ N < 2000 → 必须拟合分布（候选：对数正态、威布尔、
  │                          折叠正态；按 AD 统计量最小者选取），
  │                          用拟合分布的 X0.135%/X50%/X99.865% 计算
  │
  └─ 3. 漂移/非稳态过程（ISO 22514-2 时间相关模型）
        引擎 v1 不做自动分类，但检测到"受控性边缘 + 子组间变差远大于
        组内变差(σb/σw 比值异常)"时，在报告结论区提示：
        "疑似时间相关分布模型（C/D 类），建议按 ISO 22514-2 评价"
```

## ISO 22514-2 时间相关分布模型速览（提示用，引擎不自动套用）

| 类别 | 特征 | 典型场景 |
|---|---|---|
| A 类 | 位置、散布均恒定 | 稳态过程（经典假设） |
| B 类 | 散布恒定、位置随机变动 | 批间波动 |
| C 类 | 位置系统性变动（趋势） | 刀具磨损 |
| D 类 | 位置与散布均变动 | 复合变差 |

## 控制图类型全集（引擎 v1.1 覆盖）

AIAG-VDA 新版控制图分三大族，技能现全覆盖：

| 族 | 类型 | 适用数据 | 控制限特征 |
|---|---|---|---|
| 计量型 Shewhart | I-MR / Xbar-R / Xbar-S | 连续测量值（单值或子组） | 恒定限 |
| 计数型（属性图） | p / np / c / u | 合格判定计数 / 缺陷计数 | p、u 为**逐点（变样本量）限**；np、c 为恒定限 |
| 时间加权 | EWMA / CUSUM | 连续测量值（单值或子组均值） | EWMA 为**逐点渐缩限**；CUSUM 为双侧决策区间 |

### 计数型（属性图）公式

- **p 图（不合格品率）**：子组样本量 n_i 可不等。p̄ = Σx_i / Σn_i；σ_i = √(p̄(1−p̄)/n_i)；
  UCL_i = min(1, p̄ + 3σ_i)，LCL_i = max(0, p̄ − 3σ_i)；点值 = x_i / n_i。
- **np 图（不合格品数）**：样本量 n 恒定。np̄ = n·p̄；σ = √(np̄(1−p̄))；
  UCL = np̄ + 3σ，LCL = max(0, np̄ − 3σ)；点值 = x_i（计数值）。
- **c 图（缺陷数）**：检验单位面积/批量恒定。c̄ = mean(x)；σ = √c̄；
  UCL = c̄ + 3σ，LCL = max(0, c̄ − 3σ)；点值 = x_i（缺陷数）。
- **u 图（单位缺陷数）**：单位数 c_i 可不等。ū = Σx_i / Σc_i；σ_i = √(ū / c_i)；
  UCL_i = ū + 3σ_i，LCL_i = max(0, ū − 3σ_i)；点值 = x_i / c_i。
- **属性图共性**：不做分布拟合（无正态性检验）、不输出连续型过程能力指数（Cp/Cpk/Pp/Ppk）、不输出 ppm；仅判定合格/不合格。报告第 VII–IX 节与第 X 节显示「不适用」。

### 时间加权图公式（作用于连续数据）

- **EWMA（指数加权移动平均）**：Z_t = λ·x_t + (1−λ)·Z_{t−1}，Z_0 = 目标值（缺省取序列均值 tgt）。
  控制限逐点渐缩：UCL_i = tgt + L·σ·√(λ/(2−λ)·(1−(1−λ)^{2i}))，LCL 对称；
  稳态极限标准差 σ_E = σ·√(λ/(2−λ))。默认 λ = 0.2、L = 3.0。
  n>1 时 EWMA 作用于**子组均值**序列，σ 取子组均值的标准差（组内σ = σ·√n）。
- **CUSUM（累积和，tabular 双侧）**：
  C⁺_t = max(0, x_t − (tgt + k·σ) + C⁺_{t−1})，C⁻_t = max(0, (tgt − k·σ) − x_t + C⁻_{t−1})；
  决策区间 h·σ。默认 k = 0.5σ（检测 0.5σ 偏移最优）、h = 4.0σ。
  两序列分别作图（CUSUM+ / CUSUM−），任一越限即判异（默认仅准则 1）。
- **时间加权图共性**：仍基于连续数据，能力分析沿用底层连续数据（组内σ估计）；不改变分布/能力评价逻辑。

## 判异准则第一类错误提示

每增加一条判异准则，误报警概率约增加 10%（新版 9.2.2 原文）。引导用户按过程特点选定准则子集并成文；引擎默认仅准则1，用户明确选定后才启用更多。
