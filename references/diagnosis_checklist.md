# 新版 AIAG-VDA SPC 手册（2026 第一版）导入差距诊断清单

> 用途：模式A（企业导入诊断顾问）的提问依据。Agent 按条目**逐项向用户采集真实现状**，绝不替用户假设"应该有"。每条含：诊断问句、合规判定要点、缺口时的补救方向。
> 使用方式：不要一次抛出全部问题（禁止大问卷）。先问用户"当前导入到什么程度、最想解决什么"，再按其薄弱环节选择对应章节条目深入，每轮追问 1-3 条。

## 第5章 前置条件诊断（权重最高，先问）

### 5.1-5.4 基础输入
- 问：贵司 SPC 控制点是怎么确定的？能追溯到 FMEA/风险分析和特殊特性清单吗？
  - 合规要点：特殊特性 → 风险分析 → 控制计划 → SPC 控制点，链条可追溯。
- 问：SPC 所用的测量系统做过 MSA 吗？结果如何（GRR%、ndc）？
  - 合规要点：**MSA 先行**——测量系统未确认合格，SPC 数据视为无效。这是审核硬伤高发点。

### 5.6 OCAP（失控行动预案）★最常见缺口
- 问：控制图判异后，产线现在实际怎么处理？有成文的行动预案吗？
- 合规四要素（缺一即为缺口）：
  1. 过程调整与升级措施的**职责界定**
  2. **操作员调整矩阵**（失控重复出现或规定循环内未恢复时的动作）
  3. **过程日志**（记录调整、观察、措施）
  4. 操作员和主管**理解并会用的确认证据**（培训记录）
- 判定：只在控制计划反应栏写一句"通知班长"→ 不合规。正确形态见 references/ocap_guide.md。

### 5.7 控制计划挂接
- 问：控制计划反应计划栏目前写的是什么？能追溯到 OCAP 编号/版本吗？

### 5.8 角色与能力矩阵
- 问：操作工/质量工程师/管理层在 SPC 里各承担什么职责？有成文的能力矩阵和培训证据吗？

## 第7章 机器性能 Pm 诊断
- 问：新设备验收时做机器性能研究（Pm/Pmk）吗？验收标准里有指标要求吗？
- 合规要点：Pm 是**设备放行**评价（短期、仅设备变差），与 Pp/Ppk（过程放行）、Cp/Cpk（量产）三阶段严格区分，抽样方案与计算前提不可混用。
- 常见缺口：采购合同/设备验收规范里没有 Pm 条款——需要动跨部门流程，推进阻力最大，建议列为中期项。

## 第8章 过程表征与分布模型诊断
- 问：贵司算 Cpk 之前判断过数据分布吗？刀具磨损、批间漂移这类过程怎么评价能力？
- 合规要点：
  - 先做**过程表征**（稳定性 + 分布形态），再选能力计算方法。
  - 稳定 + 正态 → 经典公式；非正态 → 拟合分布后用 ISO 22514 分位数法；漂移/非稳态 → ISO 22514-2 时间相关分布模型（A/B/C/D 类）。
  - 用经验分位数估计须 **N ≥ 2000**，否则必须先拟合分布。
- 常见缺口：所有过程一律套正态稳态公式。

## 第9章 控制图应用诊断
- 问：现在用哪些控制图？判异用几条准则？是怎么选定的、有成文依据吗？
- 合规要点：
  - 选图前先定控制理念：**过程相关控制图 vs 公差相关控制图**。
  - 判异准则**选定并成文**，禁止默认全套叠加（每加一条准则，第一类错误概率约增 10%）。
  - 必要时用 **ARL（平均运行链长）**论证抽样方案/图种的检出力。
- 常见缺口：软件默认勾选 8 条判异全开、无选用理由文件。

## 第10章 软件 V&V 诊断
- 问：SPC 分析用什么工具（Excel 模板/MES 模块/商用软件）？做过验证与确认吗？有 V&V 记录吗？
- 常见缺口：自制 Excel 模板从未验证——可能倒逼系统升级，建议早识别。

## 第11章 报告诊断
- 问：现在的 SPC/能力报告包含哪些内容？（对照 references/report_20_elements.md 的 20 项逐项比对）
- 常见缺口：报告只有"控制图 + Cpk 值"，缺数据收集条件、测量过程描述、分布模型及验证方法、概率图、ppm 估计。

## 第12章 追溯与归档诊断
- 问：SPC 原始数据和报告的保存期限、检索方式有规定吗？能满足 IATF 16949 记录保存要求吗？

## 诊断输出格式（模式A 的交付）

诊断完成后输出「缺口清单 + 导入路线」，写入用户工作目录（txt + md 双格式）：
1. **缺口清单**：按章节列缺口，标注严重度（审核硬伤 / 重要缺口 / 改进项）。
2. **优先级与路线**：推荐顺序 = 差距分析 → 试点线跑通 OCAP + 三阶段能力评价 → 软件 V&V 与归档制度铺开。
3. **技能联动指引**：诊断到"MSA 未做"→ 提示可用 msa-analysis 技能；"控制计划反应栏未挂 OCAP"→ 提示 cp-control-plan 技能；"FMEA 链条断"→ fmea-assistant。
