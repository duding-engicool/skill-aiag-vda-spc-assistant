> 用途：模式C（计算引擎 + 可编辑报告）的合规基准。依据新版第 11 章（11.1 报告要素、11.2 格式由顾客与供应商商定、图 11-1/11-2/11-3 示例模板）。

## 引擎合规硬规则（强制执行，防误用）

1. **受控才出 Cp/Cpk**；不受控只出 Pp/Ppk，并在报告明示"过程不受控，仅报告性能指数"。
2. **N < 2000 禁用经验分位数**：非正态时必须先拟合分布（对数正态/威布尔/折叠正态），再用拟合分布的分位数计算。
3. 正态性判定用 Anderson-Darling 检验（α=0.05）；报告必须披露检验统计量与结论（要素16）。
4. 判异准则**按用户选定的子集**执行并在图上注明（要素14）；用户未选时默认仅"准则1：单点出界"，并提示按第9章成文选定。
5. 指数必须注明计算方法（正态经典公式 / ISO 22514 分位数法）。
6. 单侧规格只报 Cpk/Ppk 单侧值；缺规格则只做稳定性分析，不出能力指数。

## 计算方法约定

- 控制限：Xbar-R（A2/D3/D4）、Xbar-s（A3/B3/B4）、I-MR（2.66/3.267），系数表内置于 spc_engine.py。
- 判异准则 8 条（新版 9.2.2，与西电/尼尔森一致）：①1点出±3s ②9点同侧 ③6点连升/降 ④14点交替 ⑤3中2超±2s同侧 ⑥5中4超±1s同侧 ⑦15点居中±1s内 ⑧8点连续超±1s。
- 正态能力：Cp=(USL-LSL)/6σw，Cpk=min[(USL-μ)/3σw,(μ-LSL)/3σw]，σw=Rbar/d2 或 sbar/c4；Pp/Ppk 用总体标准差 s。
- 分位数法（ISO 22514 通用式）：Pp=(USL-LSL)/(X99.865%-X0.135%)；Ppk=min[(USL-X50%)/(X99.865%-X50%), (X50%-LSL)/(X50%-X0.135%)]。
- ppm：按所选分布模型 CDF 计算规格外比例 ×1e6。

## 可编辑报告技术约定（assets/report_template.html）

- 单文件自包含 HTML，主色 #C8102E，无外网依赖（图表用内嵌 SVG，由 Python 端预渲染 + JS 端重算重绘）。
- 编辑态/呈现态切换；可编辑字段用 contenteditable / input，锁定区随数据重算。
- 数据表可编辑 → JS 内嵌同一套公式（控制限/判异/指数/分位数）实时重算并重绘 SVG。
- 保存：localStorage 自动草稿 + 导出 JSON（数据档）+ 另存 HTML（成品档，当前状态回写）。
- 导出 PDF：@media print 打印样式（A4 分页、隐藏编辑控件），Ctrl+P 另存为 PDF；页面提供"导出 PDF"按钮调用 window.print()。
